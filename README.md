# Бісер · Облік складу

React + Vite PWA для обліку матеріалів (бісер, нитки, фурнітура) та підрахунку
собівартості наборів для виготовлення прикрас. Дані зберігаються локально в
браузері (localStorage) — окремо на кожному пристрої, поки не підключено Firebase.

## Запуск

Потрібен встановлений Node.js (18+).

```bash
npm install
npm run dev
```

Відкриється адреса на кшталт `http://localhost:5173` — відкрийте її в браузері
(або на телефоні в тій самій Wi-Fi мережі за адресою, яку Vite покаже в консолі).

## Встановлення як застосунок (PWA)

```bash
npm run build
npm run preview
```

Це збірка "продакшн" версії — саме вона встановлюється як застосунок на телефон
("Додати на головний екран" у Chrome/Safari) і працює офлайн. Для реального
хостингу зберіть `npm run build` і викладіть вміст папки `dist/` на будь-який
хостинг (Firebase Hosting, Netlify, Vercel тощо).

## Структура проєкту

- `src/App.jsx` — головний компонент, стан складу і наборів
- `src/components/` — форми та списки (склад, набори, модальні вікна)
- `src/utils/storage.js` — збереження в localStorage
- `src/utils/calc.js` — розрахунок собівартості
- `vite.config.js` — налаштування PWA (manifest, іконки, офлайн-кеш)
- `public/icons/` — іконки застосунку (замініть на власні за бажанням)

## Що є в цій версії

- Пошук і сортування (за датою, назвою, вартістю) на сторінках "Склад" і "Набори"
- Посторінкова навігація (по 8 позицій на сторінці)
- Собівартість набору показується в грн і в USD — курс задається вручну через
  кнопку ⚙ у шапці

## Наступний крок — Firebase

Коли протестуєте локальну версію, наступний крок — підключити Firebase:
Authentication (вхід через Google), Firestore (замість localStorage) та Storage
(для фото товарів і наборів замість base64). Дайте знати, коли будете готові —
допоможу перенести дані на Firebase.
